================================================================================
            Emoji Library by Kairesh Adobe CEP Extension Setup Guide
================================================================================

Emoji Library by Kairesh is a premium emoji search and insertion panel for Adobe 
After Effects and Adobe Premiere Pro. It supports Apple, Google, and Twemoji styles
with full skin-tone controls.

Follow these steps to install and activate it.

--------------------------------------------------------------------------------
METHOD 1: Automatic Installer (Windows Only)
--------------------------------------------------------------------------------
1. Right-click the `install.ps1` file located in the root of this folder.
2. Select "Run with PowerShell".
3. Wait for the success message, then restart After Effects or Premiere Pro.

--------------------------------------------------------------------------------
METHOD 2: Manual Installation
--------------------------------------------------------------------------------

STEP 1: Copy the Extension Folder
---------------------------------
Copy the entire 'emoji-library-by-kairesh' folder into your Adobe extensions folder:

* WINDOWS:
  Copy to: C:\Users\<Your_Username>\AppData\Roaming\Adobe\CEP\extensions\
  
  (Tip: Press Win + R, type '%appdata%' and hit enter. From there, navigate into
  Adobe -> CEP -> extensions. If the 'CEP' or 'extensions' folders do not exist,
  simply create them).

* MACOS:
  Copy to: /Users/<Your_Username>/Library/Application Support/Adobe/CEP/extensions/
  
  (Tip: In Finder, click 'Go' in the top menu bar, select 'Go to Folder...', 
  paste the path above, and hit enter).


STEP 2: Enable Unsigned Extensions (PlayerDebugMode)
---------------------------------------------------
Because this is a custom local development extension, you must configure Adobe to allow unsigned panels.

* WINDOWS:
  1. Click the Start Menu, type "cmd", right-click Command Prompt, and select "Run as Administrator".
  2. Copy and paste the following commands one-by-one and press Enter:
     
     reg add "HKCU\Software\Adobe\CSXS.11" /v PlayerDebugMode /t REG_SZ /d 1 /f
     reg add "HKCU\Software\Adobe\CSXS.10" /v PlayerDebugMode /t REG_SZ /d 1 /f
     reg add "HKCU\Software\Adobe\CSXS.9" /v PlayerDebugMode /t REG_SZ /d 1 /f

* MACOS:
  1. Open Terminal (cmd + space, type "terminal", press Enter).
  2. Copy and paste the following commands one-by-one and press Enter:
     
     defaults write com.adobe.CSXS.11 PlayerDebugMode 1
     defaults write com.adobe.CSXS.10 PlayerDebugMode 1
     defaults write com.adobe.CSXS.9 PlayerDebugMode 1


STEP 3: Start After Effects / Premiere Pro
------------------------------------------
1. Launch Adobe After Effects or Premiere Pro.
2. In the top menu bar, go to: Window -> Extensions -> Emoji Library by Kairesh.
3. The panel will open. Customize your style (Apple/Google/Twemoji), size, and tone, 
   then click any emoji to insert it directly!
