============================================================
           Emoji & Icon Studio for Adobe Premiere Pro & After Effects
                           Version 2.8.7
============================================================

A fast, responsive Adobe CEP extension providing instant access to
200,000+ vector icons, HD multi-platform emojis, clipboard paste, 
and local folder asset management.

------------------------------------------------------------
[ FEATURES ]
------------------------------------------------------------
• 200,000+ Vector Icons:
  Lucide, Phosphor, Tabler, Heroicons, Simple Icons (brand logos),
  Pixelarticons, Remix Icon, Bootstrap Icons, and more.
  Adjust colors and stroke widths on the fly.

• Multi-Platform HD Emojis:
  Microsoft 3D Fluent, Apple HD, Google Android, Twemoji.
  Full skin tone support.

• Native Drag & Drop:
  Drag any icon or emoji directly onto Premiere Pro Timeline
  or into the After Effects Project Panel.

• Automatic "Icons" Organization:
  All dropped or inserted items are automatically organized into
  an "Icons" bin in Premiere Pro / After Effects and saved into 
  an "Icons" folder inside your linked disk directory.

• Local Folders & Real-Time Sync:
  Link your own folders on disk. Any file added, renamed, or 
  deleted in Windows Explorer updates in the panel automatically.

• Lossless Clipboard Image Paste:
  Paste copied images or screenshots in full fidelity directly
  into your sequence or composition.

• Quick Actions:
  One-click "Clear All" recents button, folder refresh, and 
  save-to-folder shortcuts.

• In-App Updates:
  Automatic notification popup when newer releases are published 
  on GitHub with one-click update installation.

------------------------------------------------------------
[ REQUIREMENTS ]
------------------------------------------------------------
• Adobe Premiere Pro CC 2017 (v11.0) or newer
• Adobe After Effects CC 2015 (v13.5) or newer
• Windows 10/11 or macOS 10.14+

------------------------------------------------------------
[ INSTALLATION ]
------------------------------------------------------------
Method 1: ZXP Installer (Recommended)
1. Download Anastasiy's Extension Manager or ZXP Installer.
2. Drag and drop "Emoji-Library.zxp" into the installer.
3. Restart Premiere Pro or After Effects.

Method 2: Manual Folder Install
1. Extract or copy the extension folder to:
   Windows:
   %APPDATA%\Adobe\CEP\extensions\com.antigravity.emojilib

   macOS:
   ~/Library/Application Support/Adobe/CEP/extensions/com.antigravity.emojilib

2. Enable debug mode (if prompted or not loading):
   Windows (Run in Command Prompt / Terminal):
   reg add "HKCU\Software\Adobe\CSXS.7" /v PlayerDebugMode /t REG_SZ /d "1" /f
   reg add "HKCU\Software\Adobe\CSXS.8" /v PlayerDebugMode /t REG_SZ /d "1" /f
   reg add "HKCU\Software\Adobe\CSXS.9" /v PlayerDebugMode /t REG_SZ /d "1" /f
   reg add "HKCU\Software\Adobe\CSXS.10" /v PlayerDebugMode /t REG_SZ /d "1" /f
   reg add "HKCU\Software\Adobe\CSXS.11" /v PlayerDebugMode /t REG_SZ /d "1" /f

------------------------------------------------------------
[ HOW TO USE ]
------------------------------------------------------------
1. Launch Adobe Premiere Pro or After Effects.
2. Go to: Window -> Extensions -> Emoji & Icon Studio.
3. Browse emojis, icons, or linked folders.
4. Drag onto timeline / project panel, or click any item to preview, 
   customize color/size, and insert.
5. In Settings, manage custom storage, styles, and check for updates.
