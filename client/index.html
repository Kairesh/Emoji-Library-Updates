🔑 API & Token Setup Guide

Good News: Zero API Keys Are Required!

Emoji & Icon Studio is preconfigured to stream 200,000+ vector icons (Lucide, Phosphor, Tabler, Heroicons, etc.) and all Unicode emojis directly through public open CDNs. You do not need to create any account or paste any key to use 100% of the plugin features!

Optional: GitHub Personal Access Token

If you perform thousands of downloads in a short time, you can optionally provide a free GitHub token for higher rate limits:

  1. Log into your free account on GitHub.com.
  2. Click your profile picture → Settings → Developer Settings.
  3. Select Personal Access Tokens → Tokens (classic).
  4. Click Generate new token (classic).
  5. Give it any note (e.g. Emoji Studio) and click Generate token at the bottom. No extra checkboxes needed!
  6. Copy the token (starts with ghp_...) and paste it into the Settings field.
